## Most Challenging Problem

Credit

Implementing Luhn's Algorithm required breaking the problem into smaller steps:

- Process digits from right to left.
- Alternate digit multiplication.
- Sum two-digit products.
- Compute the checksum.
- Identify the card issuer.

---

## Key Concepts Learned

- Integer arithmetic using `%` and `/`
- Algorithm decomposition
- Nested loops
- Input validation
- Problem-solving in C

---

## Reflection

The Credit problem was the first exercise that forced me to stop thinking about code first and instead focus on designing the algorithm before implementing it.

Breaking the solution into small, testable steps made the implementation significantly easier.
